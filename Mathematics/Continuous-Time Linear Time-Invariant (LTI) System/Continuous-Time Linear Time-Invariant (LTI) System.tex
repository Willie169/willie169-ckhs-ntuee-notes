\sct{Continuous-Time Linear Time-Invariant (LTI) System}
\ssc{Definition}
\sssc{Causal continuous-time linear time-invariant (LTI) system}
A causal continuous-time linear time-invariant (LTI) system of a variable $t\in\bbR$ is a system that accept an input (distribution) (often called function) $x(t)$ and produces a response (distribution) (often called function) $y(t)$ that is the solution of a linear autonomous ODE whose forcing term is $x(t)$, called governing equation, given initial condition $y(0)=0$. It can be completely characterized by a distribution called impulse response (function) $h(t)$, which is the output when the input is the Dirac delta function $\delta(t)$ and is such that $h(t)=0$ for all $t<0$, that
\[y(t)=(x*h)(t)\coloneq\int_0^tx(\tau)h(t-\tau)\dd{\tau}.\]
Applying unilateral Laplace transform
\[Y(s)=X(s)\cdot H(s),\]
where $H(s)$ is a rational function called transfer function (轉移函數). Unless otherwise specified, we will discuss casual continuous-time linear time-invariant (LTI) system below.
\sssc{Non-causal continuous-time linear time-invariant (LTI) system}
A non-causal continuous-time linear time-invariant (LTI) system of a variable $t\in\bbR$ is a system that accept an input (distribution) (often called function) $x(t)$ and produces a response (distribution) (often called function) $y(t)$ that is the solution of a linear autonomous ODE whose forcing term is $x(t)$, called governing equation. It can be completely characterized by a distribution called impulse response (function) $h(t)$, which is the output when the input is the Dirac delta function $\delta(t)$, that
\[y(t)=(x*h)(t)\coloneq\int_{-\infty}^{\infty} x(\tau)h(t-\tau)\dd{\tau}.\]
Applying bilateral Laplace transform
\[Y(s)=X(s)\cdot H(s),\]
where $H(s)$ is a rational function called transfer function.
\sssc{Gain}
$\abs{H(s)}$ is called gain (增益), or attenuation (衰減量) if $<1$.
\sssc{Order}
The number of poles of $H(s)$ is called the order of the system.
\ssc{Response}
\sssc{Poles and zeros}
Since $H(s)$ is rational, a complex conjugate of a pole is a pole of same order, and a complex conjugate of a zero is a zero of same order.

A pole–zero plot or pole–zero constellation is a graphical representation showing poles and zeros of a transfer function in the complex plane.
\sssc{Transient response}
A response component that converges to an equilibrium as $t$ gets large. Such converged state is called steady state or transient state.
\sssc{Time constant}
For a response in the form
\[y(t)=A+\sum_{j=1}^nB_je^{-\frac{t}{\tau_j}}\]
with $A\in\bbR$, $B_j\ne 0$, and $\tau_j>0$.

Each $\tau_j$ is called a time constant, and the system is called a $n$-time-constant system, e.g., single-time-constant (STC), two-time-constant (TTC).

For each term
\[y_j(t)=B_je^{-\frac{t}{\tau_j}}\]
if $B_j>0$, we typically call that 
\bit
\item $y_j(t)$ decays to $0$ about $5\tau_j$.
\item The falling time or pulse decay time is defined as the time $y_j(t)$ changes from $0.9B_j$ to $0.1B_j$, which is $\ln 9\tau_j\approx 2.2\tau$.
\eit
if $B_j<0$, we typically call that 
\bit
\item $y_j(t)$ grows to $B_j$ about $5\tau_j$.
\item The rising time or pulse grow time is defined as the time $y_j(t)$ changes from $0.1B_j$ to $0.9B_j$, which is $\ln 9\tau_j\approx 2.2\tau$.
\eit
\sssc{Natural frequency}
For a pair of conjugate poles $\pm i\omega$ of $H(s)$, $\omega$ is called a natural frequency of the system.
\sssc{Resonance}
Resonance occurs when the input and transfer function have common poles on the imaginary axis. Such natural frequency is called resonant/resonance frequency.
\ssc{Stability}
\sssc{Asymptotically stable or bounded-input bounded-output (BIBO) stable}
A LTI system is called asymptotically stable or bounded-input bounded-output stable iff bounded input implies bounded response, iff all poles of it are on the left half-plane iff $h(t)$ is absolutely integrable.
\sssc{(Lyapunov) stable}
A LTI system is called (Lyapunov) stable iff there is no pole of it on the right half-plane and no multiple pole of it on the imaginary axis iff $h(t)$ is bounded.
\sssc{Marginally stable}
A LTI system is called marginally stable iff it is stable but not asymptotically stable.
\sssc{Unstable}
A LTI system is called unstable iff it is not stable.
\ssc{Frequency response}
\sssc{Frequency response}
\bit
\item $H(i\omega)$ is called frequency response,
\item $a(\omega)\coloneq\abs{H(i\omega)}$ is called magnitude/amplitude response/ratio or gain,
\item $\theta(\omega)\coloneq\arg(H(i\omega))$ (also denoted as $\varphi(\omega)$) is called phase (angle) response/shift.
\eit
$\omega$ is called angular frequency and $f\coloneq\frac{\omega}{2\pi}$ is called non-angular frequency. Both can be called frequency and can be differentiated with symbol, and angular frequency is used below.
\sssc{Steady-state sinusoidal response}
Assume the system is stable with $m$ LHP poles $a_1,\ldots,a_n$ and $n$ pure imaginary poles $b_1,\ldots,b_n$ and that $H(s)=O(1)$. When the input is $x(t)=e^{i\omega t}$, $X(s)=\frac{1}{s-i\omega}$, the response is
\[Y(s)=\frac{H(s)}{s-i\omega}.\]
\[y(t)=\frac{1}{2\pi i}\lim_{T\to\infty}\int_{\gamma-iT}^{\gamma+iT}Y(s)e^{st}\dd{s},\quad\gamma>0.\]
Close the contour from $\gamma-iT$ to $\gamma+iT$ with a semicircular contour $C_T$
\[C_T=\{\gamma+iTe^{i\theta}\colon\theta\in[0,\pi]\}\]
to form a closed contour $\Gamma_T$.
\[\ba
\abs{\int_{C_T}Y(s)e^{st}\dd{s}}&=\abs{\int_{C_T}Y(s)e^{(\gamma-T\sin\theta)t}e^{i\Im(s)t}\dd{s}}\\
                                &=\int_0^{\pi}\abs{Y(\gamma+iTe^{i\theta})e^{(\gamma-T\sin\theta)t}(-Te^{i\theta})}\dd{\theta}\\
                                &\le Te^{\gamma t}\int_0^{\pi}\abs{Y(\gamma+iTe^{i\theta})}e^{-T\sin\theta t}\dd{\theta}
\ea\]
\[Y(s)=O\qty(\frac{1}{s})\]
Suppose for some $M>0$, for all sufficiently large $|s|$,
\[\abs{Y(s)}\le\frac{M}{\abs{s}}\]
For all sufficiently large $T$,
\[\abs{\gamma+iTe^{i\theta}}\ge T-\gamma\]
\[\abs{Y(\gamma+iTe^{i\theta})}\le\frac{M}{T-\gamma}=O\qty(\frac{1}{T})\]
\[Te^{\gamma t}\int_0^{\pi}\abs{Y(\gamma+iTe^{i\theta})}e^{-T\sin\theta t}\dd{\theta}=O\qty(\int_0^{\pi}e^{-T\sin\theta t}\dd{\theta})\]
\[\int_0^{\pi}e^{-T\sin\theta t}\dd{\theta}=2\int_0^{\frac{\pi}{2}}e^{-T\sin\theta t}\dd{\theta}\]
\[\sin\theta\ge\frac{2\theta}{\pi}\]
\[e^{-T\sin\theta t}\le e^{-\frac{2T\theta t}{\pi}}\]
\[\ba
2\int_0^{\frac{\pi}{2}}e^{-T\sin\theta t}\dd{\theta}&\le 2\int_0^{\frac{\pi}{2}}e^{-\frac{2T\theta t}{\pi}}\dd{\theta}\\
                                                    &=2\frac{\pi}{2Tt}\evlp{e^{-\frac{2T\theta t}{\pi}}}_0^{\frac{\pi}{2}}\\
                                                    &=\frac{\pi}{Tt}\qty(1-e^{-Tt})\\
                                                    &\le\frac{\pi}{Tt}\\
\ea\]
\[2\int_0^{\frac{\pi}{2}}e^{-T\sin\theta t}\dd{\theta}=O\qty(\frac{1}{T})\]
\[Te^{\gamma t}\int_0^{\pi}\abs{Y(\gamma+iTe^{i\theta})}e^{-T\sin\theta t}\dd{\theta}=O\qty(\frac{1}{T})\]
Thus,
\[\lim_{T\to\infty}\int_{C_T}Y(s)e^{st}\dd{s}=0\]
\[y(t)=\frac{1}{2\pi i}\lim_{T\to\infty}\int_{\Gamma}Y(s)e^{st}\dd{s}\]
Since $H(s)$ is meromorphic, by residue theorem,
\[y(t)=\Res(Y(s)e^{st},i\omega)+\sum_{k=1}^m\Res(Y(s)e^{st},a_k)+\sum_{k=1}^n\Res(Y(s)e^{st},b_k)\]
Use Laurent series:
\[\Res(Y(s)e^{st},z)=\lim_{s\to z}(s-z)Y(s)e^{st}=e^{zt}\lim_{s\to z}(s-z)Y(s)\]
$\sum_{k=1}^m\Res(Y(s)e^{st},a_k)$ is transient response.
\bit
\item If $n=0$, the system is asymptotically stable, and
\[\Res(Y(s)e^{st},i\omega)=H(i\omega)e^{i\omega t}\]
is steady-state sinusoidal response with amplitude $a(\omega)$.
\item If $n>0$, the system is marginally stable, and:
\bit
\item If $i\omega$ is not a pole,
\[\Res(Y(s)e^{st},i\omega)+\sum_{k=1}^n\Res(Y(s)e^{st},b_k)=H(i\omega)e^{i\omega t}+\sum_{k=1}^ne^{b_kt}\lim_{s\to b_k}(s-b_k)Y(s)\]
is steady-state sinusoidal response and the second term is not transient.
\item If $i\omega$ is a pole, it is resonant response that grows to infinity over time.
\eit
\eit
\sssc{Logarithmic scale, decibel (dB), and Bode plot (波德圖)}
Frequency response are often expressed in logarithmic scale:
\bit
\item Magnitude response, input, and output can be expressed in decibel (dB) as $g(\omega)\coloneq C\log_{10}|H(i\omega)|$, $C\log_{10}|x|$, and $C\log_{10}|y|$ with some constant $C$. $C=20$ is used here.
\item Changing by 2 times is called an octave or oct, and changing by 10 times is called a decade or dec. $k$ dec$^{-1}$ equals to $\log_{10}(2)$ oct$^{-1}$. The most common used is $20$ dB/dec equals to $20\log_{10}(2)\approx 6$ dB/oct.
\eit
We can factor $H(s)$ into
\[H(s)=G\prod_{k=1}^mH_k(s)\]
then
\[a(\omega)=\abs{G}\prod_{k=1}^m\abs{H_k(i\omega)}\]
\[g(\omega)=20\log_{10}\abs{G}+20\sum_{k=1}^m\log_{10}\abs{H_k(i\omega)}\]
\[\theta(\omega)=\arg(G)+\sum_{k=1}^m\arg(H_k(i\omega))\]
\sssc{Cutoff (截止), break, or corner (angular) frequency}
For a transfer function, cutoff frequency $\omega_c$ is a frequency such that
\[\abs{H(i\omega_c)}=\frac{\max_{\omega}a(\omega)}{\sqrt{2}}.\]
$20\log_{10}(\frac{1}{\sqrt{2}})=-10\log_{10}(2)\approx -3$, thus this frequency is also denoted $\omega_{-3\tx{dB}}$ or $\omega_{3\tx{dB}}$.
\sssc{Normalizing}
For a transfer function $H(s)$ such that
\[\max_{\omega}a(\omega)=K\in\bbR_{>0},\]
normalizing means dividing $H(s)$ by $K$. The following filter definitions are normalized. Non-normalized definition is defined as any filter whose normalized form complies with the definition.
\sssc{Bode plot}
\bit
\item Bode magnitude plot or dB gain curve: Magnitude response plotted with frequency (or frequency divided by cutoff or some other important frequency) in logarithmic scale as horizontal axis and magnitude response (or, normalized magnitude response, that is, divided by maximum gain, where the Bode magnitude plot is called normalized) in dB as vertical axis.
\item Bode phase plot or phase curve: Phase response plotted with frequency (or frequency divided by cutoff or some other important frequency) in logarithmic scale as horizontal axis and phase response as vertical axis.
\item Asymptotic Bode plot: The asymptotes of Bode plots for low and high frequency is often interested.
\eit
\ssc{Filters}
\sssc{Low-pass or lowpass (低通) (LP), high-cut, or bass-cut filter (LPF)}
A continuous-time linear time-invariant system is a normalized low-pass filter iff $H(i\omega)$ as a function of a real variable $\omega$ is such that
\[\lim_{\omega\to 0}a(\omega)=1\]
\[\lim_{\omega\to\infty}a(\omega)=0\]
$K$ is called low-pass gain.

Ideal normalized low-pass filter is
\[H(i\omega)=\bcs1,\quad&\omega<\omega_0\\0,\quad&\omega>\omega_0\ecs\]
\sssc{High-pass or highpass (高通) (HP), low-cut, or treble-cut filter (HPF)}
A continuous-time linear time-invariant system is a normalized high-pass filter iff $H(i\omega)$ as a function of a real variable $\omega$ is such that
\[\lim_{\omega\to 0}a(\omega)=0\]
\[\lim_{\omega\to\infty}a(\omega)=1\]
$K$ is called high-pass gain.

Ideal normalized high-pass filter is
\[H(i\omega)=\bcs1,\quad&\omega>\omega_0\\0,\quad&\omega<\omega_0\ecs\]
\sssc{Band-pass or bandpass (BP) filter (BPF)}
A continuous-time linear time-invariant system is a standard normalized band-pass filter iff $H(i\omega)$ as a function of a real variable $\omega$ is such that
\[\lim_{\omega\to 0}a(\omega)=0\]
\[\lim_{\omega\to\infty}a(\omega)=0\]
\[\arg_{\omega}\left\{a(\omega)=\frac{1}{\sqrt{2}}\right\}=\omega_L,\omega_H\]
\[\abs{H(\sqrt{\omega_L\omega_H})}=1\]
where $\omega_L<\omega_H$ are called band edge, $\omega_H-\omega_L$ is called bandwidth, and $\omega_0=\sqrt{\omega_L\omega_H}$ is called central passed frequency or center frequency. $\omega_0\gg B$ is called narrow band-pass filter.

$K$ is called band-pass or midband gain.

Ideal normalized band-pass filter is
\[H(i\omega)=\bcs1,\quad&\omega_H>\omega>\omega_L\\0,\quad&\omega<\omega_L\lor\omega>\omega_H\ecs\]
\sssc{Band-stop or bandstop (BS), band-reject, or notch filter (BSF)}
A continuous-time linear time-invariant system is a standard normalized band-stop filter iff $H(i\omega)$ as a function of a real variable $\omega$ is such that
\[\arg_{\omega}\left\{a(\omega)=\frac{1}{\sqrt{2}}\right\}=\omega_L,\omega_H\]
\[\abs{H(\sqrt{\omega_L\omega_H})}=0\]
where $\omega_L<\omega_H$ are called band edge, $\omega_H-\omega_L$ is called bandwidth, and $\omega_0=\sqrt{\omega_L\omega_H}$ is called central rejected frequency or center frequency. $\omega_0\gg B$ is called narrow band-stop filter.

$K$ is called notch gain.

Ideal normalized band-stop filter is
\[H(i\omega)=\bcs0,\quad&\omega_H>\omega>\omega_L\\1,\quad&\omega<\omega_L\lor\omega>\omega_H\ecs\]
\sssc{Bandwidth}
The band of frequencies over which the gain is no less than 3 dB (or other value if specified, such as 0 dB for unity gain bandwidth), or the length of it if it is connected.
\sssc{Normalized low-pass prototype filter}
A normalized low-pass prototype filter is a low-pass filter with cutoff frequency $\omega_c=1$. Suppose the transfer function of it is $H_P(s)$. A normalized low-pass prototype filter is usually defined with $\qty(a(\omega))^2=H(i\omega)H(-i\omega)$ or $H(s)$.

To transform an $n$th-order normalized low-pass prototype filter to an $n$th-order low-pass filter with cutoff frequency $\omega_c$, use the transfer function
\[H_{LP}(s)=H_P\qty(\frac{s}{\omega_c}).\]
To transform an $n$th-order normalized low-pass prototype filter to an $n$th-order high-pass filter with cutoff frequency $\omega_c$, use the transfer function
\[H_{HP}(s)=H_P\qty(\frac{\omega_c}{s}).\]
To transform an $n$th-order normalized low-pass prototype filter to a $2n$th-order standard band-pass filter with cutoff frequency $\omega_c$, use the transfer function
\[H_{BP}(s)=H_P\qty(\frac{s^2+\omega_0^{\pht{0}2}}{Bs}).\]
To transform an $n$th-order normalized low-pass prototype filter to a $2n$th-order standard band-stop filter with cutoff frequency $\omega_c$, use the transfer function
\[H_{BS}(s)=H_P\qty(\frac{Bs}{s^2+\omega_0^{\pht{0}2}}).\]
\sssc{Butterworth filter or maximally flat magnitude filter}
$n$th-order Butterworth low-pass prototype filter is
\[\qty(a(\omega))^2=\frac{1}{1+\omega^{2n}}\]
\[H(s)=\prod_{k=1}^n\frac{1}{s-e^{\frac{j(2k+n-1)\pi}{2n}}}\]
For first-order,
\[\qty(a(\omega))^2=\frac{1}{1+\omega^2}\]
\[H(s)=\frac{1}{s+1}\]
When not specified, a filter of a type usually refers to the lowest-order Butterworth filter of the type.
\sssc{single-time-constant (STC) filters}
$\omega_c$ is cutoff frequency, $\tau$ is time constant, $\abs{K}$ is gain at $\omega=0$, and the following form is called standard form.

Low-pass:
\[H(s)=\frac{K}{1+\frac{s}{\omega_c}}\]
\[H(i\omega)=\frac{K}{1+i\frac{\omega}{\omega_c}}\]
\[a(\omega)=\frac{\abs{K}}{\sqrt{1+\qty(\frac{\omega}{\omega_c})^2}}\]
\[\theta(\omega)=-\arg(\frac{\omega}{\omega_c})\]
\[H(i0)=K\]
\[H(i\infty)=0\]
\[\tau=\frac{1}{\omega_c}\]
High-pass:
\[H(s)=\frac{K}{1-\frac{s}{\omega_c}}\]
\[H(i\omega)=\frac{K}{1-i\frac{\omega}{\omega_c}}\]
\[a(\omega)=\frac{\abs{K}}{\sqrt{1-\qty(\frac{\omega}{\omega_c})^2}}\]
\[\theta(\omega)=\arg(\frac{\omega}{\omega_c})\]
\[H(i0)=0\]
\[H(i\infty)=K\]
\[\tau=\frac{1}{\omega_c}\]
\ssc{Transfer function factors}
Variables after $;$ are parameters, which are positive real numbers unless otherwise specified. Only positive $\omega$ are considered.
\sssc{Reciprocal factor}
This factor is not asymptotically stable but marginally stable.
\[H_c(s;W)\coloneq\frac{W}{s}\]
\[H_c(i\omega;W)=\frac{W}{i\omega}\]
\[a_c(\omega;W)=\frac{W}{\omega}\]
\[g_c(\omega;W)=-20\log_{10}(\omega)+20\log_{10}(W)\]
\[\theta_c(\omega;W)=-\frac{\pi}{2}\]
Bode magnitude plot has slope $-20$ dB/dec, $y$ intercept $20\log_{10}(W)$, and $x$ intercept $-\log_{10}(W)$.

Limit:
\bit
\item For $\omega\gg W$:
\[a_c(\omega)\approx0\]
\[g_c(\omega)\approx -\infty\]
\item For $\omega\ll W$:
\[a_c(\omega)\approx\infty\]
\[g_c(\omega)\approx\infty\]
\eit
\sssc{Ramp factor}
\[H_r(s;W)\coloneq\frac{s}{W}\]
\[H_r(i\omega;W)=\frac{i\omega}{W}\]
\[a_r(\omega;W)=\frac{\omega}{W}\]
\[g_r(\omega;W)=20\log_{10}(\omega)-20\log_{10}(W)\]
\[\theta_r(\omega;W)=\frac{\pi}{2}\]
Bode magnitude plot has slope $20$ dB/dec, $y$ intercept $-20\log_{10}(W)$, and $x$ intercept $\log_{10}(W)$.

Limit and cutoff frequency:
\bit
\item For $\omega\gg W$:
\[a_r(\omega;W)\approx\infty\]
\[g_r(\omega;W)\approx\infty\]
\item For cutoff frequency $\omega=\omega_c=\frac{W}{\sqrt{2}}$:
\[a_r(\omega;W)=\frac{1}{\sqrt{2}}\]
\[g_r(\omega;W)=-10\log_{10}(2)\]
\item For $\omega\ll W$:
\[a_r(\omega;W)\approx0\]
\[g_r(\omega;W)\approx-\infty\]
\eit
\sssc{Low-pass factor}
\[H_{LP}(s;\omega_c)\coloneq\frac{\omega_c}{s+\omega_c}\]
\[H_{LP}(i\omega;\omega_c)=\frac{\omega_c}{i\omega+\omega_c}\]
\[a_{LP}(\omega;\omega_c)=\frac{\omega_c}{\sqrt{\omega^2+\omega_c^{\pht{c}2}}}\]
\[g_{LP}(\omega;\omega_c)=20\log_{10}(\omega_c)-10\log_{10}(\omega^2+\omega_c^{\pht{c}2})\]
\[\theta_{LP}(\omega;\omega_c)=-\arg(i\omega+\omega_c)\]
Asymptotic Bode plot and cutoff frequency:
\bit
\item For $\omega\gg \omega_c$:
\[a_{LP}(\omega;\omega_c)\approx\frac{\omega_c}{\omega}\]
\[g_{LP}(\omega;\omega_c)\approx 20\log_{10}(\omega_c)-20\log_{10}(\omega),\]
which is slant asymptote with slope $-20$ dB/dec, $y$ intercept $20\log_{10}(\omega_c)$, and $x$ intercept $\log_{10}(\omega_c)$.
\[\theta_{LP}(\omega;\omega_c)\approx0\]
\item For cutoff frequency $\omega=\omega_c$:
\[a_{LP}(\omega;\omega_c)=\frac{1}{\sqrt{2}}\]
\[g_{LP}(\omega;\omega_c)=-10\log_{10}(2)\]
\[\theta_{LP}(\omega;\omega_c)=-\frac{\pi}{4}\]
\item For $\omega\ll \omega_c$:
\[a_{LP}(\omega;\omega_c)\approx 1\]
\[g_{LP}(\omega;\omega_c)\approx 0,\]
which is horizontal asymptote $g_{LP}=0$.
\[\theta_{LP}(\omega;\omega_c)\approx-\frac{\pi}{2}\]
\eit
\sssc{High-pass factor}
\[H_{HP}(s;\omega_c)\coloneq\frac{s}{s+\omega_c}\]
\[H_{HP}(i\omega;\omega_c)=\frac{i\omega}{i\omega+\omega_c}\]
\[a_{HP}(\omega;\omega_c)=\frac{\omega}{\sqrt{\omega^2+\omega_c^{\pht{c}2}}}\]
\[g_{HP}(\omega;\omega_c)=20\log_{10}(\omega)-10\log_{10}(\omega^2+\omega_c^{\pht{c}2})\]
\[\theta_{HP}(\omega;\omega_c)=\frac{\pi}{2}-\arg(i\omega+\omega_c)\]
Asymptotic Bode plot and cutoff frequency:
\bit
\item For $\omega\gg \omega_c$:
\[a_{LP}(\omega;\omega_c)\approx 1\]
\[g_{HP}(\omega;\omega_c)\approx 0,\]
which is horizontal asymptote $g_{HP}=0$.
\[\theta_{HP}(\omega;\omega_c)\approx\frac{\pi}{2}-\frac{\pi}{2}=0\]
\item For cutoff frequency $\omega=\omega_c$:
\[a_{HP}(\omega;\omega_c)=\frac{1}{\sqrt{2}}\]
\[g_{HP}(\omega;\omega_c)=-10\log_{10}(2)\]
\[\theta_{HP}(\omega;\omega_c)=\frac{\pi}{4}\]
\item For $\omega\ll \omega_c$:
\[a_{HP}(\omega;\omega_c)\approx\frac{\omega}{\omega_c}\]
\[g_{HP}(\omega;\omega_c)\approx 20\log_{10}(\omega)-20\log_{10}(\omega_c),\]
which is slant asymptote with slope $20$ dB/dec, $y$ intercept $-20\log_{10}(\omega_c)$, and $x$ intercept $\log_{10}(\omega_c)$.
\[\theta_{HP}(\omega;\omega_c)\approx\frac{\pi}{2}\]
\eit
\sssc{Quadratic low-pass factor}
\[H_{QD}(s;\omega_0,Q)\coloneq\frac{\omega_0^{\pht{0}2}}{s^2+\frac{\omega_0}{Q}s+\omega_0^{\pht{0}2}},\quad Q\ge\frac{1}{2}\]
\[H_{QD}(i\omega;\omega_0,Q)=\frac{\omega_0^{\pht{0}2}}{-\omega^2+i\frac{\omega_0}{Q}\omega+\omega_0^{\pht{0}2}}\]
\[a_{QD}(\omega;\omega_0,Q)=\frac{\omega_0^{\pht{0}2}}{\sqrt{\frac{\omega_0^{\pht{0}2}}{Q^2}\omega^2+\omega^4+\omega_0^{\pht{0}4}-2\omega^2\omega_0^{\pht{0}2}}}\]
\[\dv{}{\omega}\qty(a_{QD}(\omega;\omega_0,Q))=\frac{-\frac{\omega_0^{\pht{0}4}}{Q^2}\omega-2\omega^3\omega_0^{\pht{0}2}+2\omega\omega_0^{\pht{0}4}}{\qty(\frac{\omega_0^{\pht{0}2}}{Q^2}\omega^2+\omega^4+\omega_0^{\pht{0}4}-2\omega^2\omega_0^{\pht{0}2})^{\frac{3}{2}}}\]
\[\evlv{\dv{}{\omega}\qty(a_{QD}(\omega;\omega_0,Q))}_{\omega=\omega_p}=0\]
\[\omega_p=\omega_0\sqrt{1-\frac{1}{2Q^2}},\quad Q>\frac{1}{\sqrt{2}}\]
\[\theta_{QD}(\omega;\omega_0,Q)=-\arg(-\omega^2+i\frac{\omega_0}{Q}\omega+\omega_0^{\pht{0}2})\]
\bit
\item If $Q\ge\frac{1}{2}$, it is a low-pass filter.
\item If $Q>\frac{1}{2}$, the maximum of $g_{QD}$ occurs at peak frequency $\omega=\omega_p=\omega_0\sqrt{1-\frac{1}{2Q^2}}$.
\item If $Q=\frac{1}{2}$, at $\omega=\omega_0\sqrt{1-\frac{1}{2Q^2}}=0$,
\[a_{QD}(\omega;\omega_0,Q)=\infty\]
\[g_{QD}(\omega;\omega,Q)=\infty\]
\item If $Q<\frac{1}{2}$, it is unstable.
\eit
Asymptotic Bode plot and center and peak frequencies:
\bit
\item For $\omega\ll\omega_0,\frac{\omega_0}{Q}$:
\[a_{QD}(\omega;\omega_0,Q)\approx1\]
\[g_{QD}(\omega;\omega_0,Q)\approx0,\]
which is horizontal asymptote $g_{QD}=0$.
\[\theta_{QD}(\omega;\omega_0,Q)\approx0\]
\item For center frequency $\omega=\omega_0$:
\[\abs{H_{QD}(i\omega;\omega_0,Q)}=Q\]
\[g_{QD}(\omega;\omega_0,Q)=20\log_{10}(Q)\]
\[\theta_{QD}(\omega;\omega_0,Q)=-\frac{\pi}{2}\]
\item If $Q>\frac{1}{2}$, for peak frequency $\omega=\omega_p=\omega_0\sqrt{1-\frac{1}{2Q^2}}$:

\sssc{Band-pass factor}
\[H_{BP}(s;B,\omega_0)\coloneq\frac{Bs}{s^2+Bs+\omega_0^{\pht{0}2}}\]
\[H_{BP}(i\omega;B,\omega_0)=\frac{iB\omega}{-\omega^2+iB\omega+\omega_0^{\pht{0}2}}\]
\[a_{BP}(\omega;B,\omega_0)=\frac{B\omega}{\sqrt{B^2\omega^2+\omega^4+\omega_0^{\pht{0}4}-2\omega^2\omega_0^{\pht{0}2}}}\]
\[\dv{}{\omega}\qty(a_{BP}(\omega;B,\omega_0))=\frac{B\qty(\omega^4+\omega_0^{\pht{0}4}-2\omega^2\omega_0^{\pht{0}2}+2\omega^3-2\omega\omega_0^{\pht{0}2})}{\qty(B^2\omega^2+\omega^4+\omega_0^{\pht{0}4}-2\omega^2\omega_0^{\pht{0}2})^{\frac{3}{2}}}\]
\[\evlv{\dv{}{\omega}\qty(a_{BP}(\omega;B,\omega_0))}_{\omega=\omega_0}=0\]
\[\theta_{BP}(\omega;B,\omega_0)=\frac{\pi}{2}-\arg(-\omega^2+iB\omega+\omega_0^{\pht{0}2})\]
Asymptotic Bode plot and center and peak frequency:
\bit
\item For $\omega\gg\omega_0,B$:
\[a_{BP}(\omega;B,\omega_0)\approx\frac{B}{\omega}\]
\[g_{BP}(\omega;B,\omega_0)\approx-20\log_{10}(\omega)+20\log_{10}(B)\]
which is slant asymptote with slope $-20$ dB/dec, $y$ intercept $20\log_{10}(B)$, and $x$ intercept $\log_{10}(B)$.
\[\theta_{BP}(\omega;B,\omega_0)\approx-\frac{\pi}{2}\]
\item For center and peak frequency $\omega=\omega_0$:
\[a_{BP}(\omega;B,\omega_0)=1\]
\[g_{BP}(\omega;B,\omega_0)=0\]
which are maxima $a_{BP}=1$ and $g_{BP}=0$.
\[\theta_{BP}(\omega;B,\omega_0)=0\]
\item For $\omega\ll\omega_0,B$:
\[a_{BP}(\omega;B,\omega_0)\approx\frac{B\omega}{\omega_0^{\pht{0}2}}\]
\[g_{BP}(\omega;B,\omega_0)\approx 20\log_{10}(\omega)+20\log_{10}(B)-40\log_{10}(\omega_0),\]
which is slant asymptote with slope $20$ dB/dec, $y$ intercept $20\log_{10}(B)-40\log_{10}(\omega_0)$, and $x$ intercept $2\log_{10}(\omega_0)-\log_{10}(B)$.
\[\theta_{BP}(\omega;B,\omega_0)\approx\frac{\pi}{2}\]
\eit
\sssc{Band-stop factor}
\[H_{BS}(s;B,\omega_0)\coloneq\frac{s^2+\omega_0^{\pht{0}2}}{s^2+Bs+\omega_0^{\pht{0}2}}\]
\[H_{BS}(i\omega;B,\omega_0)=\frac{-\omega^2+\omega_0^{\pht{0}2}}{-\omega^2+iB\omega+\omega_0^{\pht{0}2}}\]
\[a_{BS}(\omega;B,\omega_0)=\frac{-\omega^2+\omega_0^{\pht{0}2}}{\sqrt{B^2\omega^2+\omega^4+\omega_0^{\pht{0}4}-2\omega^2\omega_0^{\pht{0}2}}}\]
\[\theta_{BS}(\omega;B,\omega_0)=\arg(\frac{-\omega^2+\omega_0^{\pht{0}2}}{-\omega^2+iB\omega+\omega_0^{\pht{0}2}})\]
Asymptotic Bode plot and center frequency:
\bit
\item For $\omega\gg\omega_0,B$:
\[a_{BS}(\omega;B,\omega_0)\approx1\]
\[g_{BS}(\omega;B,\omega_0)\approx0,\]
which is horizontal asymptote $g_{BS}=0$.
\[\theta_{BS}(\omega;B,\omega_0)\approx 0\]

\[a_{BS}(\omega;B,\omega_0)=0\]
\[g_{BS}(\omega;B,\omega_0)=-\infty\]
\[\theta_{BS}(\omega;B,\omega_0)=\arg(0)=\tx{undefined}\]
\item For $\omega\ll\omega_0,B$:
\[a_{BS}(\omega;B,\omega_0)\approx1\]
\[g_{BS}(\omega;B,\omega_0)\approx0\]
which is horizontal asymptote $g_{BS}=0$.
\[\theta_{BS}(\omega;B,\omega_0)\approx0\]
\eit
